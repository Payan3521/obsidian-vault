# Orca Bots (Slack/Linear/GitHub)

> Nodo del **Mapa Tecnológico v2.6**.

## Contexto en el mapa

> [[Orca.dev]] es un **ADE (Agent Development Environment)**, open source (MIT), para macOS/Windows/Linux. No es solo un IDE con IA: orquesta **múltiples agentes en paralelo, cada uno en su propio worktree**, con **bring-your-own-agent** (Claude Code, Codex, OpenCode, Gemini, Copilot, Cline, etc.), terminal GPU, navegador Chromium integrado con *design mode*, diffs, automatizaciones programadas, **Orca Bots** que reciben tareas desde Slack/Linear/GitHub y actúan vía **MCP**, plugins y app móvil para intervenir cuando el agente te necesita.
